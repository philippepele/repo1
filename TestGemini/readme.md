#####  Using Gemini Developer API (API Key)

###### Exemple simple avec une clé API Gemini et Spring AI   

--------
1. Obtenir une clé API Gemini   
Pour commencer, vous devez obtenir une clé API gratuite.   
Créez un compte sur Google AI Studio.   
Accédez à l'interface Google AI Studio et suivez les instructions pour générer une nouvelle clé API.   
Copiez et conservez la clé en lieu sûr.   
    
2. Chargez le projet localement.   
maintenant, mettez votre clé à la place de <API KEY>, dans le fichier application.properties.   
Faites un "mvn clean install" et lancez le projet Spring "java -jar target/TestGemini-0.0.1-SNAPSHOT.jar".   

3. Ouvrez votre browser:   
http://localhost:8080/swagger-ui/index.html   
ou    
http://localhost:8080/swagger-ui-demoGemini.html   

--------

Simple Example with a Gemini API Key and Spring AI   
1. Obtain a Gemini API Key   
To begin, you need to obtain a free API key.    
Create an account on Google AI Studio.   
Go to the Google AI Studio interface and follow the instructions to generate a new API key.   
Copy and keep the key in a safe place.   

2. Load the project locally.   
Replace <API KEY> with your key in the application.properties file.   
Perform a "mvn clean install" and launch the Spring project "java -jar target/TestGemini-0.0.1-SNAPSHOT.jar".   

3. Open your browser:   
http://localhost:8080/swagger-ui/index.html   
or   
http://localhost:8080/swagger-ui-demoGemini.html
